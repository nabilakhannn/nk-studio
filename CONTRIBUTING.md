# Contributing

Thank you for helping improve NK Studio.

1. Open an issue describing the problem or proposed change.
2. Fork the repository and create a focused branch.
3. Do not commit credentials, provider output URLs, customer media or billing screenshots.
4. Run `npm ci` and `npm run check`.
5. Open a pull request and explain the user-facing effect.

Contributions are accepted under AGPL-3.0-or-later. The project name, logo and other protected brand assets remain governed by `TRADEMARKS.md` and `ASSET-LICENSE.md`.
